Other MHGU Apps

Companion fan tools by the same author. Each opens in a new tab.

  • Home — All Apps The home page listing every Monster Hunter app by the same author, MHGU, MHFU and MH3U.
  • Quest Randomizer Rolls random quests when you can't decide what to hunt.
  • Collection Tracker Tracks which weapons, armor and Palico gear you own, and what it costs to finish them.
  • Equipment Box Mirrors the in-game box — 2000 hunter slots and 1000 Palico — so you can plan where things sit.
  • Bingo Builds a bingo card of hunting goals, with a shareable seed so a group can race the same board.
  • Hunting Log Keeps a running record of your hunts — what you were after, what you wore, who came along.
  • Zenny Gauntlet A scored challenge run — fail a hunt or get carted and you lose that weapon/style combo for the rest of the run.
  • Set Builder Assemble a full set by hand and see exactly which skills it activates.
  • Weapon Trees Browse every weapon upgrade tree, with full stats on any node you click.
  • Challenge Run A permadeath challenge run — start from a root weapon, lose it on any quest failure, clear every Key Quest.
  • Charm Farm A Clicker/Idle game about beating up various Brachydios until you finally get the desired God Charms you always wanted.
  • Talisman Bingo A bingo card of talisman conditions — keep drawing charms until one finally fills the line you needed.
  • Fishing A fishing sim on the game's own tables — prepare at camp, travel to a locale, come home with the catch.
  • Armor Viewer Renders a hunter in 3D with every armor piece swappable, so you can mix and match a set.
  • Monster Viewer Renders every monster in 3D with its own motion lists, so you can watch what they actually do.

About

A fan-made viewer for the monsters of Monster Hunter 3 Ultimate, with the game's own models, textures and motion lists. Not affiliated with, endorsed by, or supported by Capcom.

Game content

Monster Hunter 3 Ultimate and all of its models, textures, animations and data tables are © CAPCOM CO., LTD. All rights reserved. Every asset here was extracted from a personally owned copy of the game and is shown for reference only.

What you are looking at

Each monster is its own archive in the game: one model, its maps and several motion lists. The clips carry no names in the game data, only numbers, so they are listed as the game stores them.

Tools used to build this

  • RevilLib / RevilToolset — by PredatorCZ (Lukas Cone) Converted MT Framework .mod meshes to glTF, .tex textures to DDS and .lmt motion lists to animation.
  • three.js Renders the scene, with GLTFLoader, OrbitControls and SkeletonUtils.
  • Pillow Converted the extracted textures during the build.

Assets

The UI textures and the MHFU font are shared with the same author's MHGU fan apps. Monster names come from the game's own text files.
